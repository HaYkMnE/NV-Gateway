# Приватность NV Gateway

Здесь перечислены все адреса, к которым обращается NV Gateway: что уходит, когда и как это отключить. Описание относится к версии 1.0.0. Код NV Gateway открыт, поэтому каждый пункт можно сверить с исходниками в этом репозитории.

## Коротко

- Промпты уходят только в NVIDIA.
- Ключи NVIDIA уходят только в NVIDIA. Автору они не передаются никогда.
- Телеметрии и аналитики в NV Gateway нет.
- Кроме NVIDIA и GitHub, приложение может обратиться ещё к двум сервисам: `api.zeroeval.com` за рейтингом моделей (включено по умолчанию, отключается) и к сервису отчётов об ошибках автора (только когда вы нажимаете **Отправить**).

## Что остаётся на компьютере

- Шлюз слушает только `127.0.0.1` (по умолчанию порт API 12000 и служебный 12001). Другие компьютеры в сети до него не достучатся.
- Локальным программам для работы с API нужен токен шлюза.
- Ключи NVIDIA хранятся зашифрованными через Windows DPAPI в `%APPDATA%\NV-Gateway\keys.json`. Если шифрование Windows недоступно, приложение откажется сохранять ключи, а не запишет их открытым текстом.
- Логи лежат в `%APPDATA%\NV-Gateway\logs`. Ключи и токены вычищаются из логов до записи.

## Куда обращается NV Gateway

### NVIDIA: `integrate.api.nvidia.com`

| Что отправляется | Когда | Как отключить |
|---|---|---|
| Промпты вашего инструмента с одним из ваших ключей | При каждом запросе инструмента | Никак: ради этого приложение и работает |
| Запрос списка моделей, без ключа | При запуске шлюза, затем раз в 24 часа | Никак |
| Запрос списка моделей с одним из ваших ключей | Когда инструмент вызывает `GET /v1/models` | Никак |
| Фиксированный тестовый промпт (`ok`) с одним из ваших ключей, чтобы проверить возможности моделей | В фоне после загрузки списка моделей | Задайте переменную окружения `GATEWAY_CAPABILITY_PROBE_DISABLE=1` |
| Добавляемый ключ, чтобы проверить, что он работает | Только при добавлении ключа | Выполняется только при добавлении ключа |

### NVIDIA: `api.ngc.nvidia.com`

| Что отправляется | Когда | Как отключить |
|---|---|---|
| Запрос публичных данных каталога, без ключа | При запуске и после истечения 24-часового кэша | Никак |

### GitHub: `HaYkMnE/NV-Gateway`

| Что отправляется | Когда | Как отключить |
|---|---|---|
| Проверка обновлений | При запуске и каждые 6 часов | Проверка автоматическая. Ничего не скачивается и не ставится без вашего согласия |

### Рейтинг моделей: `api.zeroeval.com` (LLM Stats)

| Что отправляется | Когда | Как отключить |
|---|---|---|
| Простой запрос без ключа и без ID моделей. Сопоставление идёт на вашем компьютере. Сервис видит ваш IP-адрес | Когда экраны Models, Endpoint или Settings загружают список моделей, не чаще раза в 24 часа. **Включено по умолчанию** | Настройки → **Model ranking (LLM Stats)**. Пока переключатель выключен, запросов к `api.zeroeval.com` нет. Перезапуск не нужен |

### Отчёты об ошибках: `nv-gateway-reports.nvgw-sys.workers.dev` (Cloudflare)

| Что отправляется | Когда | Как отключить |
|---|---|---|
| Очищенный список ошибок и версия приложения. Сервис видит ваш IP-адрес | Только когда вы нажимаете **Отправить** в окне отчёта | Не нажимайте «Отправить». Иначе ничего не уходит |

### Ссылки, по которым вы переходите

Ссылки в приложении (например, на GitHub или страницу пожертвований) открываются в браузере только по вашему клику.

## Ваша ответственность

Вы сами отвечаете за то, чтобы использовать ключи в соответствии с условиями NVIDIA. К запросам, которые NV Gateway отправляет в NVIDIA от вашего имени, применяется политика конфиденциальности NVIDIA.
